# רשימת קניות משותפת

אפליקציית ווב (PWA) לרשימת קניות משותפת: קטלוג מוצרים לפי קטגוריות או א-ב, רשימה פעילה, מצב קנייה כצ'ק ליסט לפי סדר המדפים, ורשימות נוספות לפי נושאים (ילדים, ריהוט, חשמל). שני הטלפונים מתעדכנים בזמן אמת, והרשימה עובדת גם בלי קליטה בסופר.

## הרצה מקומית

```bash
npm install
npm run dev
```

בלי הגדרות Supabase האפליקציה רצה במצב מקומי: הכול נשמר בדפדפן בלבד, בלי סנכרון. זה טוב לניסיון.

## חיבור לסנכרון בין שני הטלפונים (Supabase, חינמי)

1. פותחים פרויקט ב-[supabase.com](https://supabase.com).
2. ב-SQL Editor מריצים את הקובץ `supabase/schema.sql`.
3. ב-Authentication › Providers מפעילים Email (קישור כניסה) ואם רוצים גם Google.
4. ב-Authentication › URL Configuration מוסיפים את כתובת האתר (למשל `https://<user>.github.io/shopping-list/`) ל-Redirect URLs.
5. מעתיקים מ-Project Settings › API את ה-URL ואת ה-anon key לקובץ `.env` (לפי `.env.example`).

## פרסום ב-GitHub Pages

1. ב-GitHub: Settings › Pages › Source = GitHub Actions.
2. ב-Settings › Secrets and variables › Actions › Variables מוסיפים `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` (המפתח הזה ציבורי מטבעו, ההרשאות נאכפות במסד הנתונים).
3. כל push ל-main בונה ומפרסם.

בטלפון פותחים את הכתובת ובוחרים "הוסף למסך הבית".

## מבנה

- `src/lib/store.js` מצב האפליקציה, עדכון מיידי במכשיר, תור שינויים כשאין קליטה, וסנכרון בזמן אמת.
- `src/data/catalog.js` הקטלוג ההתחלתי וסדר הקטגוריות (= סדר המדפים במצב קנייה).
- `src/screens/` המסכים: רשימה, קטלוג, קנייה, כל הרשימות, כניסה והקמת בית.
- `supabase/schema.sql` טבלאות, הרשאות (כל בית רואה רק את שלו) והצטרפות עם קוד.
